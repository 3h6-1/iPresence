# Artwork

`ipresence-icon.png` is the original iPresence home-screen icon generated with
imagegen: a music note and broadcast arcs with a mint presence dot on an indigo
background. It is an opaque 1024-pixel PNG; the build derives the iPhone and iPad
icon sizes. The generation prompt is preserved in `ipresence-icon-prompt.txt`.
This project artwork is supplied under the repository's GPL-2.0 license.

## Discord activity artwork

`apple-music-ios26.webp` is the red/pink Apple Music icon supplied by the user as
`Apple_Music_icon_iOS_26.svg.webp`. It is copied byte for byte, without modification,
for display in the Discord activity. Discord downloads it from the public raw
GitHub URL used by `PresenceUpdater.m`.
